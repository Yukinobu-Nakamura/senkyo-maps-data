# senkyo-maps-data

[senkyo-maps](https://github.com/Yukinobu-Nakamura/senkyo-maps)(選挙・政治活動マップツール)が実行時に読み込む**公開統計データの置き場**です。
地図ツール本体のリポジトリが GitHub Pages の容量上限(1GB)に近いため、追加データをここに分けて置いています。

## kb/ — 街区(○番)の境界データ
- 出典: **政府統計の総合窓口(e-Stat)「令和2年国勢調査 基本単位区境界データ(JGD2011)」**(総務省統計局)を加工して作成
  (調査区ポリゴンを街区単位に統合・属性を最小化・gzip)。加工スクリプト: senkyo-maps `build/make_kihon_tanniku.py`
- 形式: `kb_<市区町村コード5桁>.geojson.gz`(GeoJSON FeatureCollection を gzip)
  properties: `n` 町丁目名 / `b` 街区符号(2桁) / `s` 世帯数 / `j` 人口 / `u` 統合した調査区数(2以上のとき)
- 用途: 🔍地名検索で「池袋三丁目62番」のように番地まで入力したとき、その街区を枠で囲む
- 注意: 境界は調査区(道路中心線)に基づき、住居表示の実際の街区と完全には一致しません。2020年時点の区割りです。
  住居表示を実施していない(地番)地域では「○番地」と対応しません。
- `kb_index.json`: 収録コード一覧

## muni/ — 市区町村の外周
- 出典: e-Stat「令和2年国勢調査 小地域(町丁・字等)境界データ」の町丁目を市区ごとに統合(unary_union)して作成。
  加工スクリプト: senkyo-maps `build/make_muni_outline.py`
- `muni_<市区町村コード5桁>.geojson.gz`(区・市の外周)／`city_<最小区コード>.geojson.gz`(政令市など「市 > 区」構成の市全体)／`muni_index.json`
  properties: `n` 名称 / `c` コード / `s` 世帯数合計 / `j` 人口合計 / `u` 統合した町丁目数
- 用途: 🔍地名検索で「豊島区」「横浜市」と入力したとき、その範囲全体を枠で囲む
- 注意: 水面調査区(海・湖)を含まないため、海岸部は陸側で閉じます(行政界と完全には一致しません)。2020年時点の区割りです。
